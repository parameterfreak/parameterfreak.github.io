## H-MAS를 만들게 된 배경

온프레미스 환경에서 AI 모델을 서빙하다 보면 몇 가지 반복되는 문제를 만나게 됩니다.

GPU 서버가 여러 대 있지만 각각 독립적으로 운영되어 통합 관리가 어렵고, 기본 Kubernetes 스케줄러는 GPU의 물리적 토폴로지(PCIe, NUMA, 인터커넥트)를 고려하지 않아 하드웨어 성능을 온전히 활용하기 어렵습니다. 모델 배포 과정도 수동 작업이 많아 운영 부담이 큽니다.

**H-MAS**(Hardware-aware Multi-Cluster AI Serving Platform)는 이런 문제를 해결하기 위해 만들고 있는 온프레미스 AI 서빙 플랫폼입니다. 물리적으로 분산된 GPU 서버들을 하나의 컨트롤 플레인에서 관리하고, 하드웨어 토폴로지를 인식하여 모델을 최적의 GPU에 배치합니다.

---

## 주요 기능

### 멀티 클러스터 통합 관리

여러 Kubernetes 클러스터를 Push/Pull 모드로 등록하고, 하나의 컨트롤 플레인에서 관리합니다. 클러스터별 GPU 가용량, 노드 상태, 워크로드 현황을 통합 대시보드에서 확인할 수 있습니다.

### 웹 콘솔 기반 모델 배포

모델 선택, 서빙 런타임 선택, 리소스 설정, 배치 정책 지정까지 웹 UI에서 수행합니다. vLLM, llama.cpp, TEI 등 프로덕션급 서빙 런타임을 지원하며, 배치 정책에 따라 적합한 클러스터에 자동으로 스케줄링됩니다.

### 하드웨어 인지 스케줄링

GPU 간 인터커넥트 대역폭, PCIe 토폴로지, NUMA 구조를 인식하여 모델을 최적의 GPU에 배치합니다. 대형 모델(70B+)의 Tensor Parallelism 시 GPU 간 통신 병목을 최소화하고, 소형 모델은 GPU 공유를 통해 활용률을 높입니다.

벤치마크 결과:
- 대형 모델: 처리량 1.5~1.7x 향상, 지연시간 29~42% 감소
- 소형 모델: GPU 활용률 25% → 90%+, 비용 효율 2~3x 개선

### 자동 장애 복구

클러스터 장애 발생 시 설정된 정책에 따라 워크로드를 다른 클러스터로 자동 재배치합니다.

## 현재 개발 상황과 로드맵

현재 H-MAS는 멀티 클러스터 관리, 웹 콘솔, 대시보드, 배포 파이프라인, JWT 인증, 설치 자동화 등 핵심 소프트웨어 스택 개발을 완료하고, 2026년 4월 Developer Preview(v0.4.0)를 출시했습니다.

| 시점 | 버전 | 내용 |
|------|------|------|
| **4월** | **v0.4 (DP)** | ✅ Developer Preview — 멀티 클러스터 관리, 기본 서빙, 대시보드 |
| 5~6월 | — | 모니터링, 추론 프록시, RBAC, 멀티테넌시, GP 스케줄링 엔진 |
| **7월** | **v0.7 (FP)** | Feature Preview — Control Plane 고도화, GP 서빙 엔진 |
| 8~9월 | — | 고성능 GPU 토폴로지 인식 스케줄링, 모델 로딩 가속 |
| **9월** | **v0.9 (TP)** | Technical Preview — 전체 기능 통합 검증, 성능 벤치마크 |
| 10월~1월 | — | 프로덕션 안정화, UI/UX 고도화, 운영 도구 |
| **2027년 2월** | **v1.0 (GA)** | General Availability — 프로덕션 레디, 서비스 실증 |

v0.4에서는 기본 Kubernetes 스케줄러 환경에서 멀티 클러스터 관리, 웹 콘솔 배포, 대시보드, JWT 인증, 원커맨드 설치를 지원합니다. 하드웨어 인지 스케줄링(GPU 토폴로지 인식)은 v0.9에서 제공됩니다. 파일럿 파트너에게는 매월 새로운 기능이 포함된 업데이트를 제공합니다.

## 파일럿 프로그램

H-MAS를 다양한 실 환경에서 검증하기 위해 파일럿 파트너를 모집합니다. GPU 인프라를 보유한 조직에서 H-MAS를 설치하고 사용해보면서, 개발자와 직접 소통하며 제품을 함께 개선해 나가는 프로그램입니다.

v0.4.0이 출시된 현재, 미팅을 통해 서로의 환경과 니즈를 확인하고 바로 온보딩을 시작할 수 있습니다.

### 제공 조건

| 항목 | 내용 |
|------|------|
| 제품 라이센스 | 2026년 무상 제공 |
| 기술지원 | 2026년 무상 지원 (개발자 직접 대응) |
| 업데이트 | 월별 새 버전 적용 |
| 로드맵 | 파트너 피드백을 개발 우선순위에 반영 |

### 대상

- GPU 서버(2장 이상)를 보유한 조직
- AI 모델 서빙에 관심이 있거나 이미 운영 중인 곳
- Kubernetes 클러스터를 운영하고 있는(또는 구축 예정인) 곳
- 스타트업, 연구소, 대학 연구실, 중소기업 인프라팀

### 파트너에게 부탁드리는 것

- H-MAS를 설치할 Kubernetes 클러스터 환경 제공
- 월 1회 정도 사용 피드백 공유 (형식 자유)
- 이슈 발생 시 함께 확인 (원격 지원)

### 진행 과정

```
4월      ✅ Developer Preview(v0.4.0) 출시 완료
현재     파트너 모집 및 온보딩 진행 중
5~9월    월별 업데이트 + 피드백 기반 개선
9월      Technical Preview(v0.9) — 통합 검증 완료
```
