# H-MAS Iteration 29 작업 노트

이번 Iteration 29 기간(6월 28일 ~ 7월 4일) 작업 내용을 안내합니다. 이번 작업에는 13개 커밋, 13개 PR이 포함되어 있습니다. 멤버 클러스터를 실제 환경에서 등록부터 해제까지 전 과정으로 검증하며 온보딩·오프보딩 경로의 안정성을 끌어올린 기간이었습니다.

하이라이트는 다음과 같습니다:

- **클러스터 해제 라이프사이클 강건화** — 해제 시 실행 네임스페이스가 무기한 정리 대기에 고착되던 문제와 멤버 클러스터에 인증 부산물이 잔존하던 문제를 해소하여, 클러스터 등록·해제를 반복해도 잔여 리소스가 남지 않도록 정리 경계를 견고하게 만들었습니다.
- **클러스터 등록 자격증명 검증 강화** — 자격증명 없이 등록이 조용히 성공하고 클러스터가 사용 불가 상태로 남던 문제를, 등록 시점에 접속 정보를 즉시 검증해 명확한 원인과 함께 거부하도록 개선했습니다.
- **GPU 스케줄러 적용 불변식 확립** — GPU 서빙 워크로드가 배포 경로와 무관하게 지정된 전용 스케줄러로 배치되도록 보장하고, 실제 적용된 스케줄러를 인스턴스 화면에서 확인·경고할 수 있게 하여 스케줄링 오배치를 관측 가능하게 했습니다.
- **배포 전 스케줄러 사전 검증** — 스케줄러가 준비되지 않은 클러스터에 서빙 배포가 조용히 대기 상태로 고착되던 문제를 배포 시점 사전 검증으로 차단했습니다.
- **GPU 배포 무중단 업데이트 안정화** — 단일 GPU 환경에서 배포 업데이트가 상호 대기로 멈추던 문제를 해소했습니다.
- **대시보드 알림 벨 통합** — 알림 개수에 따라 대시보드 화면 구성이 깨지던 문제를 해결하고, 알림을 상단 벨의 집계 뷰로 일원화했습니다.
- 그 외 멤버 클러스터 온보딩 통합 가이드, v0.7 사용자 시나리오 워크스루, 시스템 관리자 권한 모델 리서치 등 문서 정비를 함께 진행했습니다.
