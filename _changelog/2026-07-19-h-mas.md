# H-MAS Iteration 31 작업 노트

이번 Iteration 31 기간(7월 12일 ~ 7월 18일) 작업 내용을 안내합니다. 이번 작업에는 22개 커밋, 18개 PR이 포함되어 있습니다.

하이라이트는 다음과 같습니다:

- 클러스터 해제 절차를 재설계하여, 해제 시 멤버 클러스터에 배포되었던 리소스(토큰 시크릿 포함)가 남김없이 자동 회수되도록 개선했습니다. 해제 요청은 즉시 접수 후 백그라운드로 처리되며 진행 상태가 표시됩니다.
- 스케줄러와 모니터링 컴포넌트가 클러스터 등록만으로 자동 배포되고 해제 시 자동 회수되도록 전환했습니다 — 수동 설치 절차 없이 등록 약 29초 만에 전 컴포넌트가 준비되며, GPU 감지 수동 보정 단계도 불필요해졌습니다.
- 외부(타망) 멤버 클러스터의 메트릭을 안정적·안전하게 수집하기 위한 아키텍처를 확정하고, 원격 클러스터 메트릭 미수집·클러스터 식별 불일치 결함을 해소했습니다.
- 멤버 클러스터 재연결 시 이전 잔여 리소스로 모니터링이 중단되던 문제를 자동 복구(self-healing) 구조로 해결하고, 메트릭 수신 단절을 진단해 화면에 경고로 표시하는 기능을 추가했습니다.
- 개발 브랜치 전략과 자동 배포(CD) 파이프라인을 구축하여, 코드 반영 즉시 검증 환경에 자동 배포되는 상시 검증 루프를 확보했습니다. 화면에서 현재 배포 버전도 확인할 수 있습니다.
- 유휴 상태 이후 페이지 이동 시 로그아웃되던 세션 유지 문제를 해결했습니다 — 보안 수명 정책은 그대로 유지하면서 사용자 경험만 개선했습니다.
- 클러스터 등록 후 지원 GPU 타입을 API로 수정할 수 있게 되었고, 관련 데이터의 정합성 관리 체계를 정비했습니다.
- 대시보드 비주얼 아이덴티티를 전면 개편했습니다 — 엔지니어링 도면 모티프의 새 디자인과 다크 테마(테마 토글)를 도입하고, 전 페이지의 색상 체계·접근성(명도 대비)을 정비했습니다.
- 그 외 페이지 헤더 고정(스크롤 잘림 해소), 로고 렌더링 정리, 검증 환경 설치 구성 기록 등 자잘한 개선.
