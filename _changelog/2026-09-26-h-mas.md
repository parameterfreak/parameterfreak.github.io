# H-MAS Iteration 41 작업 노트

이번 Iteration 41 기간(9월 20일 ~ 9월 26일) 작업 내용을 안내합니다. 이번 작업에는 19개 커밋, 19개 PR이 포함되어 있습니다.

하이라이트는 다음과 같습니다:

- 기본 제공 모델을 온보딩 스타터 세트로 재편했습니다 — 2024년 기준 구세대 17종 대신 설치 직후 바로 배포가 성공하도록 검증된 Qwen3·Gemma 3 계열 6종을 제공합니다. 소형 4종은 CPU 환경에서 실제 배포와 한국어 추론 응답까지 확인했으며, 그 외 모델은 등록 폼으로 직접 추가하면 됩니다. 인터넷이 차단된 온프레미스 환경 전제는 그대로 유지됩니다.
- 삭제된 조직에 남아 있던 클러스터 배정 때문에 모든 조직의 배포 생성이 막히던 문제를 해결했습니다 — 조직을 삭제하면 배정된 클러스터가 자동으로 해제되고, 기존에 남아 있던 잘못된 배정도 함께 정리됩니다. 삭제된 조직으로의 새 배정 요청은 거부됩니다.
- CPU 환경에서 비스트리밍 추론 호출이 일괄 시간 초과로 실패하던 문제를 해결했습니다 — 응답 대기 시간을 기본 300초로 늘리고 운영 환경에 맞게 조정할 수 있게 했습니다. 시간 초과 시에는 스트리밍 호출로 재시도하도록 안내합니다.
- 진행 중인 설정 변경을 롤백하면 설정 변경 이력에도 정확히 반영됩니다 — 취소된 변경이 "적용 완료"로 남고 롤백 기록이 빠지던 불일치를 바로잡아, 이력 화면이 실제 배포 설정과 일치합니다.
- 키보드와 보조 기술 사용자를 위한 접근성을 전반적으로 정비했습니다 — 대화상자와 사이드 패널을 닫으면 포커스가 열었던 위치로 돌아가고(메뉴에서 연 경우 포함), 추론 로그와 설정 이력 행을 키보드로 열 수 있으며, 아이콘 버튼 22곳에 읽을 수 있는 이름을 부여했습니다.
- 배포 삭제 시 멤버 클러스터의 워크로드가 남지 않도록 기본 배치 전략의 기본값을 바꿨습니다 — 기존 기본값은 설계 당시의 오독에서 비롯된 것으로, 재검토 후 실제 운영 환경에서 삭제 후 리소스가 완전히 정리되는 것을 확인했습니다.
- 모니터링 설정 변경이 재시작 없이 즉시 반영됩니다 — 제어 평면과 멤버 클러스터 양쪽에서 설정 리로드가 실패하던 문제를 수리하고 실제 환경에서 무재시작 반영을 검증했습니다.
- 배포 설정 화면의 고급 설정에서 통합 설정과 중복되던 항목을 제거했습니다 — 같은 값을 두 곳에 보여 혼동을 주던 문제가 사라지고, 양자화 옵션은 실제로 동작하는 방식만 남겼습니다.
- Pod 로그 뷰어를 개선했습니다 — 화면 높이에 맞게 패널이 넓어지고, 최신순/시간순 정렬을 선택할 수 있으며, 아래쪽을 보고 있을 때만 새 로그를 따라가도록 자동 스크롤을 수리했습니다.
- 버전 계획을 재편했습니다 — v1.0 GA 날짜 계획을 폐기하고 v0.9 이후 v0.10, v0.11 순으로 정기 마이너 버전을 올립니다. v1.0은 GA 기준을 충족하는 시점에 부여합니다. 추론 프록시는 현재 Push 모드 클러스터를 대상으로 완료했으며, 에이전트 기반 Pull 모드는 v0.10에서 진행합니다.
- 그 외 조직 미소속 관리자의 프리셋 조회 화면 정상화, 모델 카테고리·접근 제한 배지 표기 통일, 프리셋 중복 생성 시 충돌 응답 일관화, 보안 스캔 오탐 정리 및 CI 액션 버전 고정 등 자잘한 개선.
