# H-MAS Iteration 32 작업 노트

이번 Iteration 32 기간(7월 19일 ~ 7월 25일) 작업 내용을 안내합니다. 이번 작업에는 14개 커밋, 14개 PR이 포함되어 있습니다.

하이라이트는 다음과 같습니다:

- 배포 삭제 후 백그라운드 정리가 끝날 때까지 "정리 중"/"정리 실패" 상태가 목록에 표시됩니다. 삭제 직후에도 시스템이 무엇을 하고 있는지 확인할 수 있습니다.
- 정리 상태가 극단적인 장애 상황에서 잔류하더라도 자동으로 탐지·복구하는 자체 복구 체계를 추가해, 관리자 개입 없이 상태가 항상 수렴합니다.
- 고아 리소스 자동 정리를 실제 운영 환경에서 검증 완료하고(장기 잔존 리소스 전량 회수), 관리자가 확인 후 개별 정리할 수 있는 수단도 추가했습니다.
- 컨테이너 이미지 저장소 정리 자동화가 정식 릴리즈 이미지까지 삭제한 문제를 전량 복구하고, 릴리즈 이미지 보호를 다중 안전장치로 강화했습니다.
- 사이드바가 화면 크기에 맞춰 반응합니다 — 데스크톱 접기, 태블릿 아이콘 레일, 모바일 오버레이 메뉴를 지원하며 접근성 레이블도 보강했습니다.
- 신규 설치 환경에서 페이지 이동마다 발생하던 큐 조회 오류와, 클러스터 등록 직후 간헐적으로 표시되던 내부 오류 문구를 해결했습니다.
- 중앙 알림 시스템의 설계를 확정하고 구현 단계를 분해했습니다 — 여러 화면에 흩어진 알림을 한곳에서 읽음 관리와 함께 제공할 예정입니다.
- 그 외 CI 워크플로우 경량화(중복 실행 제거), 문서용 UI 스크린샷 자산 갱신(라이트/다크 40장), 클라우드 GPU 비용 인용 근거 문서 정비 등 자잘한 개선.
