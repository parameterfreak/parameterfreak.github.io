# H-MAS Iteration 38 작업 노트

이번 Iteration 38 기간(8월 30일 ~ 9월 5일) 작업 내용을 안내합니다. 이번 작업에는 14개 커밋, 14개 PR이 포함되어 있습니다.

하이라이트는 다음과 같습니다:

- 조직 관리자가 자기 조직의 감사 로그를 직접 조회할 수 있습니다 — 설정 메뉴에 조직 감사 로그 화면이 추가되었고, 감사 기록이 조직·그룹 단위로 자동 귀속되어 조직 관리자에게 실제 활동 내역이 표시됩니다. 대시보드 진입만으로 관리자 재인증 창이 뜨던 문제도 함께 정리했습니다.
- 관리자 모드를 만료 전에 클릭 한 번으로 연장할 수 있습니다 — 비밀번호 재입력 없이 10분씩 연장하되, 연장 이력이 감사 기록으로 남고 최초 인증 후 총 1시간을 넘기면 재인증을 요구해 관리자 모드가 무한히 유지되지 않도록 했습니다.
- 조직 관리자가 시스템 관리자 개입 없이 자기 조직에 신규 계정을 만들어 바로 멤버로 등록할 수 있습니다 — 멤버 추가와 조직 관리자 지정 화면에 "신규 계정 생성" 모드가 추가되었고, 조직 도메인과 다른 이메일은 외부 멤버로 자동 표시됩니다. 관리자 콘솔 사용자 목록에서 소속 조직과 역할을 한눈에 확인할 수 있습니다.
- 클러스터 상세 화면에 "노드 리소스" 탭이 추가되었습니다 — 노드별 CPU·메모리·디스크 사용률과 네트워크 수신/송신량, 그리고 클러스터 전체의 시간대별 추이를 확인할 수 있습니다. 새 인프라 설치 없이 기존 모니터링 구성만으로 동작합니다.
- 조직 간 데이터 격리를 추가로 강화했습니다 — 배포 메트릭 조회와 정책 단건 조회에서 다른 조직의 ID를 지정해 내용을 볼 수 있던 경로를 차단했고, 시스템 관리자 계정이 조직 관리자 자격으로 멤버를 추가할 때 불필요하게 관리자 모드 전환을 요구하던 문제를 수정했습니다.
- 컨테이너 이미지·배포 설정 보안 검사 기준을 HIGH 등급까지 차단하도록 강화했습니다 — 기반 이미지를 최신 버전으로 갱신해 알려진 취약점을 해소하고, 모든 컨테이너가 비루트 권한으로 실행되도록 배포 설정을 정비했습니다.
- 외부 도메인으로 운영하는 환경을 보완했습니다 — 클러스터별 외부 접근 주소를 설정하면 인스턴스의 직접 엔드포인트가 도달 가능한 주소로 표시되고, 클러스터 등록 시 인증서 요건을 안내하는 가이드가 추가되었습니다.
- 그 외 관리자 쓰기 API 22개 Swagger 문서화, 큐 중복 실행 테스트의 간헐적 실패 해소 등 자잘한 개선.
