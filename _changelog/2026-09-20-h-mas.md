# H-MAS Iteration 40 작업 노트

이번 Iteration 40 기간(9월 13일 ~ 9월 19일) 작업 내용을 안내합니다. 이번 작업에는 8개 커밋, 8개 PR이 포함되어 있습니다.

하이라이트는 다음과 같습니다:

- 모델 메타데이터를 H-MAS가 직접 보관합니다 — 모델을 등록하는 시점에 아키텍처·컨텍스트 길이·라이선스·도구 호출 지원 여부 등을 수집해 저장하고, 기본 제공 모델 17종은 사전 수집된 정보가 함께 제공됩니다. 배포나 화면 표시 시점에 외부 서비스를 호출하지 않으므로 인터넷이 차단된 온프레미스 환경에서도 동일하게 동작하며, 외부 접근이 불가한 경우 수동 입력도 지원합니다.
- 인스턴스 상세 화면에서 배포된 모델과 현재 서빙 설정을 한눈에 확인할 수 있습니다 — 모델 정보 카드가 포맷·양자화·파일 크기·라이선스·주요 기능을 보여주고, 새 서빙 최적화 카드가 실제 적용 중인 설정값을 모델 최대치와 나란히 표시합니다. 설정한 컨텍스트 길이가 모델 한도를 넘으면 경고로 알려 줍니다.
- 모델 저장소에서 배포 전에 모델 상세 정보를 볼 수 있습니다 — 카드 제목을 누르면 컨텍스트 길이·접근 제한 여부·라이선스·최소 리소스 요건·출처를 확인할 수 있어, 기존처럼 배포를 마친 뒤에야 확인하던 불편이 해소됩니다. 목록의 검색·필터 상태는 그대로 유지됩니다.
- 조직에 소속되지 않은 시스템 관리자에게 일반 메뉴의 쓰기 버튼이 노출되던 문제를 해결했습니다 — 화면 권한 판정을 실제 조직 멤버십 기준으로 통일해 백엔드가 거부할 동작은 처음부터 보이지 않으며, 관리자 콘솔의 정상 동작은 그대로 유지됩니다. 실제 운영 환경에서 8개 항목을 검증했습니다.
- 정책을 동시에 생성·가져올 때 발생하던 서버 오류를 정리했습니다 — 같은 이름의 정책이 동시에 등록되면 이제 "이미 존재함" 충돌 응답으로 안내합니다. 데이터 정합성은 이전에도 보장되었으며 응답 코드만 바로잡은 것입니다.
- 배포 상태 기록과 실제 클러스터 상태가 어긋날 때 자동으로 맞춰집니다 — 클러스터에서 직접 복제본 수를 바꾼 경우에도 H-MAS 기록이 실제 값으로 수렴하고, 설정 변경 후 기록 저장에 실패하면 성공으로 위장하지 않고 명시적인 오류를 반환합니다.
- 최적화 프리셋을 비활성 상태로 생성하면 그대로 비활성으로 저장됩니다 — 명시적으로 꺼둔 설정이 켜진 상태로 뒤바뀔 수 있던 잠재 결함을 제거하고 회귀 테스트를 추가했습니다.
- 그 외 멀티테넌시 권한 문서에 장애 복구 정책 항목을 반영, 설계 스펙 4건 추가 등 자잘한 개선.
