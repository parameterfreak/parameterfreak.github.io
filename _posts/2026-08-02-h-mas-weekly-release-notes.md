# H-MAS Iteration 33 작업 노트

이번 Iteration 33 기간(7월 26일 ~ 8월 1일) 작업 내용을 안내합니다. 이번 작업에는 12개 커밋, 12개 PR이 포함되어 있습니다.

하이라이트는 다음과 같습니다:

- 중앙 알림 시스템을 완성했습니다 — 배포 이상, 클러스터 다운, 고아 리소스, 작업 큐 적체 알림이 서버에 기록되고, 문제가 해소되면 자동으로 사라집니다. 브라우저를 새로 열어도 놓친 알림을 확인할 수 있습니다.
- 알림 벨에 읽지 않은 알림 수 배지와 읽음 처리가 추가되고, 전체 알림 이력을 상태·종류·심각도로 필터링해 열람하는 알림 센터 페이지가 신설되었습니다.
- 권한이 없거나 존재하지 않는 배포에 접근할 때마다 서버 로그에 오류 기록이 쌓이던 장기 잔존 결함을 근본적으로 해결했습니다.
- PR 생성 전에 CI 차단 검사 전체를 로컬에서 미리 재현하는 사전 검증 도구를 도입해, CI 실패 후 재작업하는 왕복을 없앴습니다.
- 주간 보안 스캔에서 심각 등급 발견 시 즉시 통지되도록 가시성을 강화하고, 중복 스캔을 제거해 효율을 개선했습니다.
- 관리자 권한 체계 개선 착수에 앞서 설계 문서를 현행 코드 기준으로 전면 재검토·현행화해 구현 범위를 정확히 재산정했습니다.
- 그 외 최근 기능 변경의 기술문서 반영, 활용 사례 문서에 서버 점검 시나리오 추가, 개발 빌드 실행 결과에 빌드 버전 표시 등 자잘한 개선.
