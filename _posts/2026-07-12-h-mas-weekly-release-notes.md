# H-MAS Iteration 30 작업 노트

이번 Iteration 30 기간(7월 5일 ~ 7월 11일) 작업 내용을 안내합니다. 이번 작업에는 12개 커밋, 12개 PR이 포함되어 있습니다. v0.7.0 Feature Preview를 정식 릴리즈하고, 릴리즈 후 실환경 검증에서 발견된 멀티테넌시 격리 및 배포 안전망 결함을 즉시 해소한 기간이었습니다.

하이라이트는 다음과 같습니다:

- **v0.7.0 Feature Preview 릴리즈** — Feature Preview 마일스톤 완료에 따라 v0.7.0을 정식 발행했습니다. 릴리즈 이미지의 보안 취약점 점검 기준을 통과시키는 보안 업데이트를 포함했으며, 릴리즈 절차를 표준화해 향후 릴리즈의 누락·재작업을 예방했습니다.
- **멀티테넌시 격리 강화** — 한 조직의 그룹 정보와 모델 저장소 접근 토큰이 다른 조직에 배정된 클러스터에서도 보일 수 있던 문제를 근본 차단했습니다. 이제 조직별 리소스는 해당 조직 소유 클러스터에만 배포되며, 기존에 잘못 배포된 리소스도 자동으로 회수됩니다.
- **자동 배치 사전 검증 확대** — 클러스터를 자동 선택하는 배포 경로에서 준비가 완료되지 않은 클러스터로 배치가 확정되어 배포가 조용히 대기 상태에 고착되던 문제를, 배포 시점 사전 검증으로 차단하고 명확한 원인과 함께 거부하도록 개선했습니다.
- **배포 실패 사유 표시** — 배포가 원인 표시 없이 '대기 중'으로 영구 표시되던 문제를 해소했습니다. 이제 회복 불가능한 실패는 실패 상태와 사유, 관련 이벤트로 정직하게 드러납니다.
- **클러스터 해제·조직 변경 안전장치** — 활성 배포가 남아 있는 클러스터를 해제하거나 조직을 변경하려 할 때, 대상 배포 목록을 안내하고 정리 후 진행하도록 사전 확인 절차를 추가했습니다.
- **사용자별 API 사용량 한도 및 계정 상태 즉시 반영** — 로그인 사용자별로 API 요청량 한도를 개별 설정할 수 있게 되었고, 비활성화·삭제된 계정은 발급된 토큰이 남아 있어도 즉시 접근이 차단됩니다.
- **GPU 클러스터 관리 요구사항 분석 및 가격정책 개편** — GPU 클러스터 관리 솔루션 요구사항 6개 영역에 대한 대응 수준을 분석하고, 가격정책을 구축형(On-Prem) 단일 모델 중심으로 개편했습니다.
- 그 외 이미지 사전 캐싱 설정이 갱신되지 않던 오류 수정, v0.7.0 릴리즈 반영 기술 문서 정합화 등 자잘한 개선.
